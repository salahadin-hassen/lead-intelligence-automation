          IF LLM UNAVAILABLE → DETERMINISTIC FALLBACK
        

      


      

        

          
Intelligence / Deterministic by design

          

            FastAPI applies validation, business rules and scoring. PostgreSQL holds persistent records. The LLM is configurable; deterministic fallback provides an alternative when model scoring is unavailable.
          

        

        

          
Action / Configuration sets the route

          

            n8n orchestrates the workflow and routes qualification paths. Notifications use configured channels only; a route does not imply successful delivery.
          

        

      


      Architecture design — verified with 97 automated tests and end-to-end rehearsal drills.
    

  


  
  

    

      

        
        Chapter 04 / Operational Resilience
      


      

        

          
Clarity includes what happens when it doesn’t work.

          

            
No silent assumptions.

            

              Handling principles implemented to prevent data loss, eliminate duplicate alerts, and guarantee auditability under stress.
            

          

        


        

          

            
Input validation

            
Required information and format checks surface actionable field errors.

            CHECK THE INPUT
          


          

            
Duplicate handling

            
Potential matches are made explicit before a record is treated as new.

            PRESERVE CONTEXT
          


          

            
Scoring fallback

            
Use deterministic rules when configured model scoring cannot provide a usable result.

            KEEP A FALLBACK
          


          

            
Explicit qualification paths

            
Represent qualified, not qualified and manual review as distinct possible routes.

            NAME THE NEXT STEP
          


          

            
Observable workflow failures

            
Expose uncertain outcomes. Check records before retrying to avoid duplicates.

            DO NOT ASSUME DELIVERY
